# UK_News_Scrapers

This repository holds a collection of RSS scrapers for UK news outlets that were used in a field experiment in late 2023 with the Informfully news app. The resulting study has since been published in the Journal of Communication: https://doi.org/10.1093/joc/jqaf019 

The repository holds finished scrapers (production), unfinished experiments (development) and data from test retrievals (data).
